🚀 1. Executive System Overview

DOCURE is an intelligent, privacy-conscious clinical healthcare assistant designed to bridge patient triage, AI-driven pathology report diagnostics, real-time medical facility dispatching, and automated medication schedule compliance. The application operates as a high-performance Single Page Application (SPA) leveraging edge AI models, real-time spatial APIs, and serverless persistence.

🔬 3. NVIDIA AI Lab Report Analyzer Pipeline

The Pathology OCR engine is built on a dual-strategy architecture that dynamically switches between client-side digital text extraction and multimodal visual transformer parsing:

[Step 1: Upload] User uploads Diagnostic PDF or Photo (Dr Lal / SRL / Thyrocare)
  ├── IF PDF: Mozilla PDF.js parses binary text & row coordinates (lossless text)
  └── IF IMAGE: Canvas downscales to 1280px & converts to Base64 JPEG payload
[Step 2: NIM API] Proxied through /api/nvidia to prevent CORS & securely sign key
  ├── PDF Route: Meta Llama 3.1 70B Instruct (Prompt: Serial Biomarkers Extraction)
  └── Image Route: Meta Llama 3.2 90B Vision Instruct (Visual layout OCR)
[Step 3: Classifier] Balanced JSON parser categorizes biomarkers into HIGH, NORMAL, LOW
[Step 4: Insights] Produces Health Score (0-100), positive insights, risks & specialist referral.
Pipeline Component Technology Used Role in System
Text LLM Model meta/llama-3.1-70b-instruct Processes dense lab texts, computes clinical ranges, formats serial JSON.
Vision LLM Model meta/llama-3.2-90b-vision-instruct Scans image tables, letterheads, and photographed medical papers.
Client PDF Parser PDF.js (pdfjs-dist 3.11) In-browser canvas rendering and coordinate-grouped text line reconstruction.
Reverse Proxy Vite HTTP Proxy Middleware Routes localhost calls to integrate.api.nvidia.com without browser CORS blocks.

⏰ 5. Medication Scheduler & Background Daemon

The reminder subsystem is engineered as an autonomous background listener that ensures patients never miss scheduled dosages:

🔥 Cloud Firestore

Stores user medications under users/{uid}/reminders. Synchronizes instantaneously across tabs via onSnapshot.

⏱️ Polling Daemon

A background worker wakes up every 20 seconds, evaluates current time against scheduled dose hours, and triggers alarms.

🔔 In-App Toast & Audio

Synthesizes soft multi-frequency soundwaves with Web Audio API and presents actionable reminder cards with dose logging.

🚨 6. Web Audio Synthesis & Emergency Override

DOCURE includes browser-native multi-media pipelines that require zero external audio assets:

📢 Emergency Siren Synthesizer

Generates dual-frequency ambulance wails (850Hz & 650Hz alternate square waves) using AudioContext.createOscillator(). Initiates countdown to dispatch coordinates to pre-saved emergency links.

🎙️ Speech Recognition & TTS

Integrates browser webkitSpeechRecognition for hands-free voice triage in Hindi/English, alongside window.speechSynthesis for reading clinical answers aloud.
